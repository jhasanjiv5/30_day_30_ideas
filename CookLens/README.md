# CookLens — Native iOS App Project (.xcodeproj)

CookLens is an **iOS-native SwiftUI application** designed for **iOS 18+**. It uses Apple Vision's on-device image classifier to analyze captured photos and offers rule-based recipe ideas for ingredients it recognizes.

This repository is structured as a **native Xcode Application Project (CookLens.xcodeproj)** ready to open and run directly in Xcode.

---

## Quick Start (Running in Xcode)

1. Double-click or open **CookLens.xcodeproj** in Xcode 16.0+:
   open CookLens.xcodeproj
2. Select an **iOS 18 Simulator** (e.g., iPhone 16 Pro) or your connected physical iPhone.
3. Press **Cmd+R** (Product -> Run).

## Technical Highlights

1. **Native SwiftUI App Target**: A full Xcode application target (com.apple.product-type.application).
2. **On-Device Image Classification**: Apple Vision runs image classification locally. No custom vision-language model or generative model is bundled.
3. **Transparent Recipe Suggestions**: Recipe ideas are selected from recognized ingredients using local rules; they are not generated by a language model.
4. **Interactive Grocery & Store Routing**: MapKit integration provides nearby store routing for missing ingredients.
5. **Hands-Free Cooking**: Step-by-step cooking guidance includes speech synthesis.
